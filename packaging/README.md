# Packaging & Distribution Assets — OpenClone

OpenClone is distributed as an extension-first Universal AI Engineering Platform via:

- Python Core/Runtime package (`pyproject.toml`)
- Visual Studio Code Extension (`OpenClone-2.0.0.vsix`)
- Google Antigravity Plugin and MCP server (`src.openclone.mcp.server`)

Standalone CLI executable packaging (PyInstaller / Inno Setup) has been retired.
