# KNOW-0001: Four-Set Intelligence Architecture

OpenClone organizes project planning through four canonical intelligence sets:
1. **Set A — Feature Intelligence:** Product requirements, market positioning, competitor analysis.
2. **Set B — Gap & Problem Intelligence:** Static inspection, code defects, architectural debt, UX friction.
3. **Set C — Solution Intelligence:** Technical alternatives, complexity estimations, acceptance criteria.
4. **Set D — Final Product Blueprint:** Consolidated, traceable master architecture ready for implementation.
