# PREF-0001: Code Style & Anti-Slop Guidelines

- **Zero Speculative Success:** Never claim a task, build, or test passed without executing actual verification commands.
- **Fail-Closed Execution:** Planning phases halt before target-project code execution begins without cryptographic human approval.
- **Deterministic Code:** Strictly typed Python with PEP 484 type annotations and comprehensive Docstrings.
- **Design Authenticity:** Reject generic AI gradients and rounded card tropes; enforce WCAG 2.2 AAA accessibility.
