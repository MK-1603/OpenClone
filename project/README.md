# OpenClone Project Layer

This directory contains standard project templates and configurations for initializing OpenClone governance inside any software engineering project.

## Contents

- `PROJECT.md.template`: Canonical project specification and source-of-truth contract.
- `AGENTS.md.template`: Operational operating contract for AI coding agents.
- `host-rules/`: Host-specific rule templates for Antigravity, Claude Code, Cursor, etc.
- `.openclone/`: Standard local state directory skeleton (config, state, checkpoints, ledger).
