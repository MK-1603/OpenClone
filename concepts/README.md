# OpenClone Core Concepts & Architectural Alternatives

OpenClone is built on modular, deterministic software engineering principles. To support diverse development environments—from high-assurance regulated enterprise platforms to rapid autonomous prototyping—every fundamental concept in OpenClone is structured with:
1. **A Primary Canonical Specification (`.md`)**: The battle-tested, hardened, zero-trust default.
2. **A Separate Alternate Specification (`.alternate.md`)**: A fully realized, clean alternative paradigm with documented trade-offs, suitability criteria, and migration paths.
