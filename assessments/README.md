# OpenClone Engineering Assessments & Baselines

This directory contains formal engineering baselines, technical audits, and gap analyses governing OpenClone subsystems prior to architectural modification.

## Directory Structure

- `model-intelligence/`: Architectural assessments, baseline matrices, and conformance audits for the Model Intelligence Engine (MIE).
  - [`MIE-BASELINE.md`](model-intelligence/MIE-BASELINE.md): Comprehensive baseline audit, provider taxonomy (P0-P2), task intelligence classification, 6-dimension scoring, tri-state circuit breakers, and zero-dependency HTTP provider abstractions.
- `requirements/`: Requirements systems audits and traceability matrices.
