# OpenClone Visual Assets & Brand Kit

This directory contains visual brand assets, diagrams, and vector illustrations for OpenClone:

- `openclone-wordmark.svg`: Canonical OpenClone vector wordmark and banner.
- `architecture-topology.svg`: 4-layer architectural topology diagram (Hosts, Shared MCP Server, Deterministic Control Plane, Knowledge & Workforce).
- `lifecycle-diagram.svg`: 7-phase instruction-first verified engineering lifecycle diagram.
