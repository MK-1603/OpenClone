## 3. Logo Concept & Design Intent

- **Concept Name:** Architectural Hexagon Prism & Code Glyph (`CONCEPT-01-PRISM`)
- **Logo Category:** `COMBINATION_MARK`
- **Design Intention:** Combines an isometric 3D hexagonal framework with an embedded code glyph `</>`, signifying foundational software architecture and deterministic control.
- **Brand Meaning:** The outer hexagon symbolizes structural stability and systemic containment; the inner code terminal represents developer-first execution and technical clarity.

## 5. Geometric Construction & Grid Rules

- **Baseline Unit Grid:** 8px orthogonal grid system.
- **Proportion Ratio:** Golden Ratio (1.618) ($1 : 1.6180339887$).
- **Symmetry & Balance:** Bilateral symmetry along central vertical axis with optical compensation.
- **Clear-Space Rule:** Maintain an exclusion buffer around all edges of the mark equal to at least **25% of the mark's height** ($X$-height clearance). No text, borders, or graphics may encroach within this zone.
- **Minimum Digital Dimensions:** 24px width for screen displays.
- **Minimum Physical Dimensions:** 10.0mm width for offset or digital print.

## 9. Incorrect Usage & Anti-Slop Rules

To maintain brand dignity, the following treatments are **strictly prohibited**:

1. **NO Generic AI Glow Blobs:** Do not add diffuse neon gradients or purple/cyan fog behind the mark.
2. **NO Aspect Ratio Distortion:** Never stretch, compress, skew, or shear the logo. Always scale proportionally.
3. **NO Unauthorized Palettes:** Do not recolor facets with unapproved random hues.
4. **NO Low-Contrast Canvases:** Do not place the primary logo on mid-tone grey backgrounds where contrast drops below 3.0:1.
5. **NO Dropshadow Clutter:** Do not apply heavy 2000s-era Gaussian drop-shadows.

## 10. Vector Master Specifications

All master assets are generated as standard-compliant, editable SVG:
- Vector standard: W3C SVG 1.1 / SVG 2.0 with valid `viewBox`.
- Encoding: UTF-8 without BOM.
- Purity: Zero embedded base64 raster blobs; 100% genuine vector geometry.
- Portability: Renderable across web browsers, Node.js, Python, Figma, and Inkscape.
