## Brand Engineering Principles

1. **Deterministic Preservation:** The approved visual identity, isometric hexagonal prism emblem, and wordmark are preserved across all variants.
2. **Pure Vector Scalability:** All SVGs contain genuine mathematical paths and polygons with responsive `viewBox` coordinates; zero embedded raster blobs.
3. **WCAG 2.1 AA Accessibility:** Contrast ratios exceed 4.5:1 on light and dark canvases.
4. **Anti-Slop Standard:** Zero generic AI rainbow gradients, glowing orbs, or faux-glass blur clutter.
