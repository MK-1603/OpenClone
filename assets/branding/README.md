# OpenClone Brand Assets

This directory contains the canonical visual brand assets for OpenClone.

## Brand Assets

| Asset | Description | Format | Dimensions |
|---|---|---|---|
| [`openclone-logo.png`](openclone-logo.png) | Official OpenClone logo banner featuring the 3D isometric hexagonal emblem, custom wordmark, and the canonical tagline: *"Build with Any AI. Governed by One Engineering Standard."* | PNG | 850 × 283 px (Retina 2x available) |

## Usage Guidelines

- **Primary Logo Banner:** Use `openclone-logo.png` centered at the top of the repository `README.md` and official portal pages.
- **Aspect Ratio:** Always preserve the original 3:1 aspect ratio. Do not stretch, distort, crop, or recolor.
- **Tagline:** The official tagline is: *"Build with Any AI. Governed by One Engineering Standard."*
- **Emblem:** The isometric hexagonal emblem signifies deterministic multi-layered engineering governance around autonomous code generation.
