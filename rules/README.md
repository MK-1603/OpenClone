# OpenClone Native Plugin Rules

This directory contains always-on governance and quality rules automatically loaded when the OpenClone plugin is installed in Google Antigravity.

## Active Rules
- `AGENTS.md`: Always-on instruction-first and least-privilege governance contract.
- `anti-slop.md`: Taste Skill v2.6.0 prohibitions against generic AI gradients, blur blobs, and low-contrast UI.
- `security.md`: 19-point SaaS security baseline (Row-Level Security, parameterized queries, IDOR protection, zero secrets).
- `evidence.md`: Independent verification rules requiring tangible proof (code diff, test output, screenshot) before advancing task status.
