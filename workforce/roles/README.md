# Workforce Roles

Defines 73 specialist engineering roles across 7 primary functional departments:
- **Principal Architect:** System topology, capacity dimensioning, and ADR governance.
- **Product Architect:** Requirement elicitation, user journey design, and PRD specification.
- **UX/UI Designer:** Design token architecture, fluid typography, and anti-slop visual systems.
- **Frontend Engineer:** Component implementation, state management, and WCAG accessibility.
- **Backend Engineer:** Modular monoliths, microservice boundaries, and transaction safety.
- **Database Engineer:** Relational schema design, index optimization, and RLS policies.
- **Security Engineer:** STRIDE threat modeling, secret scanning, and boundary enforcement.
- **QA Engineer:** End-to-end integration testing, test fixtures, and coverage metrics.
- **DevOps Engineer:** CI/CD automation, cloud provisioning, and release gates.
- **Independent Verifier:** Cryptographic validation of completion claims and evidence artifacts.
