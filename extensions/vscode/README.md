# OpenClone for Visual Studio Code
## Governed AI Software Engineering Intelligence

OpenClone brings deterministic AI software engineering, autonomous task decomposition, and workforce governance natively into Visual Studio Code.

### Features
- **OpenClone Explorer:** Dedicated sidebar for project overview, task execution plans, workforce monitoring, and audit ledger state.
- **Task Planning:** Decompose user stories into topologically sorted execution steps with risk assessment.
- **Governed Execution:** Execute tasks with automated verification and tamper-evident cryptographic evidence.
- **Verification Gates:** Instant quality checks, test suite execution, and link validation.

### Commands
- `OpenClone: Inspect Workspace Context`
- `OpenClone: Generate Implementation Plan`
- `OpenClone: Execute Governed Engineering Task`
- `OpenClone: Run Quality Gates & Verification`
- `OpenClone: Manage Runtime Connection`
