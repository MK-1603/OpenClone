# OpenClone IDE Extensions Directory

This directory contains native IDE extension source packages for the OpenClone platform integration ecosystem.

## Structure

- `vscode/`: Visual Studio Code and Cursor native extension package containing manifest (`package.json`), Activity Bar views, command contributions, vector assets, and runtime scripts.

## Standards & Usage

Refer to [OPENCLONE_EXTENSION_ARCHITECTURE.md](../docs/architecture/OPENCLONE_EXTENSION_ARCHITECTURE.md) and [OPENCLONE_IDE_COMPATIBILITY_MATRIX.md](../docs/reference/OPENCLONE_IDE_COMPATIBILITY_MATRIX.md) for full architectural specifications, packaging guides, and tested platform versions.
