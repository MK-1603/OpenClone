## Overview

**NoteDigest** is a deterministic meeting and text digest application. It parses unstructured text, meeting transcripts, and raw notes to extract:

- **Key Decisions:** Architecture and product choices recorded during discussions.
- **Action Items & Ownership:** Assigned deliverables with `@owner` detection and explicit deadlines.
- **Open Questions & Blockers:** Unresolved items requiring follow-up.
- **Executive Summaries:** Concise synthesis with word count metrics.

---

## Engineered with OpenClone Capabilities

This demo project showcases the unified capabilities of the **OpenClone Platform**:

1. **Constitutional Governance:** Governed by [`PROJECT.md`](PROJECT.md) (Source of Truth) and [`AGENTS.md`](AGENTS.md) (Operating Contract).
2. **Brand Engineering (LEBIS):** Brand identity, vector marks (`assets/logo-primary.svg`, `assets/logo-mark.svg`), and [`assets/BRAND-GUIDELINES.md`](assets/BRAND-GUIDELINES.md) generated by `openclone brand engineer`.
3. **Agency Workforce Orchestration:** Specialist team handoff chain generated by `openclone agency team --type website`.
4. **Deterministic Control Plane:** Task DAG, human approval gates, state transitions, and tamper-evident audit ledger.

## Quickstart

### 1. Run the Application
```bash
python src/app.py
```

### 2. Digest Any Custom Note File via CLI
```bash
python -m notedigest.cli path/to/transcript.txt
```
To output JSON:
```bash
python -m notedigest.cli path/to/transcript.txt --json
```

### 3. Run the Test Suite
```bash
python -m unittest discover -s tests -v
```

### 4. Run the Full OpenClone Live Demonstration
Run the automated end-to-end demo exercising OpenClone governance, approvals, engine processing, and ledger verification:
```bash
python run_demo.py
```
