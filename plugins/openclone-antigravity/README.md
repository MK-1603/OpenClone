# OpenClone for Google Antigravity
## Universal AI Engineering Platform Plugin

OpenClone embeds enterprise-grade autonomous engineering, 31 domains, 56 capability engines, and a 72-role workforce control plane natively into Google Antigravity.

### Features
- **Repository Intelligence:** Non-destructive codebase x-ray, git status, and architecture mapping.
- **Task Planning:** Topological task decomposition with risk assessments and critical path identification.
- **Autonomous Execution:** 12-stage governed execution lifecycle (`REQUEST` to `DELIVER`) with bounded repair.
- **Workforce Management:** Coordination of 72 specialized worker contracts.
- **Verification Scorecard:** Automated test running, link checking, and tamper-evident audit ledger hashing.

### Included Customizations
- **MCP Server:** Exposes 43 tools over JSON-RPC 2.0 stdio.
- **Skill:** `openclone-engineering` procedural skill for Antigravity agents.
- **Agent:** `openclone-engineer` specialized autonomous subagent.
- **Rules:** Non-negotiable deterministic governance rules in `rules/AGENTS.md`.
