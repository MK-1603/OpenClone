# OpenClone Platform Plugins Directory

This directory contains native platform plugin packages for the OpenClone universal integration ecosystem.

## Structure

- `openclone-antigravity/`: Official Google Antigravity IDE marketplace plugin package adhering to Antigravity plugin specifications:
  - `plugin.json`: Plugin manifest and configuration.
  - `mcp_config.json`: Model Context Protocol server stdio definition.
  - `skills/`: Antigravity procedural skills for autonomous engineering.
  - `agents/`: Antigravity subagent specifications.
  - `rules/`: Antigravity deterministic governance rules.
  - `hooks.json`: Antigravity lifecycle hooks.
  - `assets/`: Vector branding and icons.
