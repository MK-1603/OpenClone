# UI/UX Engineering Skill

## Purpose
Guarantees premium, responsive, accessible user interfaces without generic AI aesthetic slop or mobile layout breakage.

## Key Steps
1. Design mobile layouts concurrently with desktop layouts (320px to 1440px+).
2. Apply Taste Skill design tokens (morphism, neutral color palette, typography scales).
3. Ensure all interactive controls have minimum 44x44px touch targets.
4. Prevent unintended horizontal overflow (overflow-x: hidden).
5. Verify WCAG AA color contrast and ARIA labels.
