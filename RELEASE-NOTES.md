## 4. Upgrading to OpenClone v2.0.0

OpenClone v2.0.0 is a zero-clone, drop-in framework. It can be consumed directly as an Antigravity plugin, VS Code extension, or headless Python module:

```bash
# As an Antigravity Plugin
agy plugin install https://github.com/MK-1603/OpenClone

# Validate repository integrity
python tools/validate_repository.py

# Execute full verification test suite
pytest tests/ -q
```
