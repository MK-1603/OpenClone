# Universal Project Intelligence Plugin for Google Antigravity

**Plugin ID:** `universal-project-intelligence`  
**Display Name:** Universal Project Intelligence  
**Version:** `1.0.0`  
**License:** MIT  

---

## Overview

The Universal Project Intelligence plugin equips Google Antigravity and AI coding agents with the capability to:
1. **Intake and Classify Any Project:** Natural-language intake and repository scanning across 12 project families and 20+ types.
2. **Deterministic Routing:** Route requirements to mandatory, conditional, and supporting engineering domains (`00-GOVERNANCE` through `30-AGENT-RULES-AND-VERIFICATION`).
3. **Capability Mapping:** Select verified capability engines (`E-001` through `E-056`).
4. **Workforce Composition:** Assemble the minimum effective team across native OpenClone agents, Agency external specialists, and human fallback.
5. **Model Matching:** Pair project complexity with MIE model intelligence (GPT-6.2 Astra, Sol, Terra, Claude, Gemini, Ollama).
6. **Blueprints:** Provide authoritative architectural blueprints for Web, Mobile, Desktop, AI, ML, Data Science, Data Engineering, Backend, OS/Linux, Embedded, Games, DevTools, and Scientific Software.

---

## MCP Tools Provided

This plugin communicates through the OpenClone Model Context Protocol (MCP) server:
- `openclone_classify_project`
- `openclone_route_project`
- `openclone_get_blueprint`
- `openclone_project_intelligence_status`
