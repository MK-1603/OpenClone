# Product Discovery Skill

## Purpose
Identifies core user needs, business constraints, market alternatives, and project scope boundaries before code generation begins.

## Key Steps
1. Identify target users and primary problems.
2. Define non-goals and explicit scope boundaries.
3. Assess technical feasibility and security boundaries.
4. Document unknowns rather than guessing.
5. Record discovery outputs in Section 1-4 of PROJECT.md.
