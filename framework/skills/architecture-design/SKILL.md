# Architecture Design Skill

## Purpose
Establishes modular component boundaries, data flow diagrams, technology selections, and security zoning.

## Key Steps
1. Select architectural pattern (modular monolith, microservices, offline-first, RTOS).
2. Evaluate technology stack options against licensing and operational cost.
3. Design API contracts and data schemas.
4. Establish security threat model and data classification.
5. Populate Section 10-14 of PROJECT.md and ARCHITECTURE.md.
