# Requirements Engineering Skill

## Purpose
Creates structured, versioned, traceable requirements with stable IDs (FR-01, NFR-01) and explicit acceptance criteria.

## Key Steps
1. Define functional capabilities with inputs, outputs, and failure behaviors.
2. Define performance, security, and reliability constraints (NFRs).
3. Specify user journeys and error states.
4. Map requirements to canonical domain capabilities.
5. Populate Section 6-9 and 18 of PROJECT.md.
