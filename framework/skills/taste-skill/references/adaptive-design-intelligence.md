# Adaptive Design Intelligence: Domain-Specific Design Standards

**Operating Rule:** Form follows business domain and user task. Never apply a generic aesthetic across distinct verticals.

---

## 1. The 16 Product Verticals Matrix

| Product Domain | Primary User Need | Information Density | Recommended Visual Language | Prohibited Anti-Patterns |
|---|---|---|---|---|
| **1. Developer Tools** | Efficiency, CLI/Code clarity | High | High contrast, monospace tokens, compact tables, keyboard shortcuts, subtle borders. | Bloated cards, slow animations, floating decorative graphics. |
| **2. Enterprise Dashboards** | Rapid status scanning, precision | High | Clean grid, tabular numbers, muted neutral backgrounds, distinct state colors. | Oversized hero sections, decorative 3D models, giant gaps. |
| **3. Financial Applications** | Numerical accuracy, trust, safety | High | Monospaced digits (`tabular-nums`), explicit +/- color conventions, clear transaction confirmations. | Translucent glassmorphism, playful bouncing animations. |
| **4. Healthcare & Medical** | Trust, calm reassurance, WCAG AAA | Moderate | Ample white space, calming slate/blue tones, high-contrast legible sans-serifs. | Neon highlights, jarring dark mode defaults, busy backgrounds. |
| **5. AI Platforms** | Understanding capability & output | Moderate | Clean demonstration of inputs/outputs, real prompts, interactive playground UI. | Generic glowing brain icons, purple nebula blobs, empty hype. |
| **6. SaaS Platforms** | Workflow accomplishment | Moderate | Clear visual hierarchy, logical left-to-right user progression, persistent navigation. | Distracting scroll-jacking, low-contrast text on images. |
| **7. Productivity Apps** | Focus, low cognitive friction | High | Minimal chrome, keyboard-first focus rings, collapsible sidebars, quiet neutrals. | Excessive celebratory modal popups, decorative badges. |
| **8. E-Commerce** | Product inspection, checkout speed | Moderate | High-resolution photography, clear pricing, prominent stock/size selectors. | Hidden pricing, unoptimized heavy images, vague shipping cues. |
| **9. Education & Learning** | Reading comprehension, progress | Moderate | Highly legible typography, clean distraction-free reader mode, visible progress tracking. | Dense walls of unchunked text, low-contrast quiz elements. |
| **10. Portfolio Websites** | Craft demonstration, distinct voice | Curated | Bold typographic pairings, editorial photography, signature interactive moment. | Generic template grids, fake project claims. |
| **11. Marketing Sites** | Value communication, conversion | Moderate | Direct plain copy, real product screenshots, transparent pricing tables. | Vague buzzword headlines, placeholder device vectors. |
| **12. Mobile Applications** | Tap accuracy, thumb-zone ergonomics | Compact | 48px minimum touch targets, native sheet interactions, safe-area padding. | Tiny hover-only interactions, viewport overflow scrolling. |
| **13. Admin Panels** | Batch operations, auditability | High | Dense data tables, batch selection toolbars, unambiguous destructive buttons. | Hidden actions under multi-level hover menus. |
| **14. Data-Heavy Applications**| Comparative analysis, filtering | Maximum | Sortable columns, clear chart legends, accessible data visualization tokens. | Inflexible fixed-width cards, decorative non-scaled charts. |
| **15. Developer Documentation**| Code discovery, copyability | High | Instant search, sticky table of contents, one-click code copy buttons, version tags. | Non-copyable code images, distracting floating banners. |
| **16. Consumer Apps** | Approachability, delightful utility | Moderate | Warm balanced palette, responsive feedback states, intuitive micro-animations. | Impenetrable enterprise jargon, intimidating dense forms. |
