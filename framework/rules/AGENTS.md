# OpenClone Always-On Governance Rule

- **Instruction-First:** Read approved project requirements and contracts before modifying any source code.
- **Truthful Maturity:** Never claim a feature, adapter, test, or security scan passed without executing it and capturing observable output.
- **Scope Lock:** Do not perform unprompted refactoring, formatting overhaul, or dependency additions outside the approved task.
- **Least Privilege:** Enforce sandbox boundaries and zero-secrets policy across all file writes and tool calls.
- **Human Authority:** AI agents propose; authorized human engineers decide. Destructive operations and production rollouts require explicit cryptographic sign-off.
