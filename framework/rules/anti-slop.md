# OpenClone Taste Skill v2.6.0 Anti-Slop Rules

- **Prohibited Clichés:** Reject generic purple gradients on black, ambient background blur blobs (`backdrop-filter: blur`), floating marketing badges, and meaningless buzzword cards.
- **Typography First:** Enforce an 8-point typographic scale, functional whitespace, high-contrast body text (`4.5:1` minimum), and native system font stacks.
- **Token Governance:** All colors, borders, shadows, and spacing must use verified CSS semantic tokens supporting both light and dark themes.
- **State Completeness:** Every interactive component must implement default, hover, active, focus, disabled, loading, and empty states.
