# Registries

Canonical indexes for engines, rules, adapters, components, and technologies. Registry status must reflect evidence; unknown capabilities remain NOT_VERIFIED.

- [Engine Registry](ENGINE-REGISTRY.md) — All 56 core engineering capability engine contracts (`E-001` to `E-056`).
- [Component Registry](COMPONENT-REGISTRY.md) — 150+ vetted accessible open-source component primitives across 20 component families.
- [Skill Registry](SKILL-REGISTRY.md) — 45 engineering specialist skills, precedence hierarchies, and gates.
- [Rule Registry](RULE-REGISTRY.md) — Deterministic engineering governance and compliance rules.
- [Technology Registry](TECHNOLOGY-REGISTRY.md) — Technology radar, stack ratings, and polyglot framework evaluations.
- [Adapter Registry](ADAPTER-REGISTRY.md) — IDE, environment, and runtime adapters.
- [Memory Adapter Registry](MEMORY-ADAPTER-REGISTRY.md) — Project context and memory vault interfaces.
