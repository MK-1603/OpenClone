# OpenClone Executable Workflows

Workflow specifications define deterministic lifecycle gates, input/output contracts, and handoff protocols. Workflows define policy and sequence; execution is delegated to authorized tools, AI coding agents, and human owners.

## Featured Core Workflows

| Workflow | Title | Category | Scope |
|---|---|---|---|
| [`WF-015`](WF-015-PORTABLE-PROJECT-SPECIFICATION-TO-BUILD.md) | **Portable Project Specification to Build** | Project Orchestration | **Zero-install workflow.** Turns a single `PROJECT.md` into verified delivery via ChatGPT/Claude and local AI IDEs. |
| [`WF-014`](WF-014-APPLICATION-BUILD-TO-DEPLOYMENT.md) | **Application Build to Deployment** | Release & Operations | 7-phase user application build, preview environment testing, and gated cloud deployment. |
| [`WF-013`](WF-013-PROJECT-DEFINITION-ASSESSMENT-AND-IMPLEMENTATION-PLANNING.md) | **Project Definition & Assessment** | Planning & Governance | End-to-end orchestration uniting `PROJECT.md`, task planning, and evidence validation. |
| [`WF-001`](WF-001-NEW-PROJECT-FROM-DOCUMENT.md) | **New Project from Document** | Project Initiation | Greenfield bootstrap from user brief to verified architecture, tasks, and initial milestone. |
| [`WF-002`](WF-002-EXISTING-PROJECT-XRAY.md) | **Existing Project X-Ray** | Discovery & Audit | Comprehensive brownfield audit, mapping dependencies, technical debt, and security gaps. |
