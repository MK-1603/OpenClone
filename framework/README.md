# OpenClone Framework Core

This directory contains the normative specifications, engines, workflows, workforce models, schemas, and templates comprising the OpenClone Universal AI Software Engineering Platform.

## Directory Structure

- `engines/`: The 56 capability engine execution specifications (E-001 through E-056).
- `workflows/`: The 14 executable lifecycle workflow procedures (WF-001 through WF-014).
- `modes/`: The 3 operational modes (Discovery, New Project, Existing Project).
- `agents/`: Specialist agent specifications and orchestration models.
- `rules/`: Repository rules and engineering constraints (AGENTS, anti-slop, evidence, security).
- `workforce/`: 72 specialist engineering worker roles, team structures, and role contracts.
- `domains/`: The 31 engineering domain specifications (00-GOVERNANCE through 30-OBSERVABILITY).
- `methodology/`: Core methodology standards:
  - `mk-framework/`: Canonical MK Framework venture-to-software execution method.
  - `egm/`: EGM-inspired workflows, prompts, and review artifacts.
- `schemas/`: JSON schemas governing work units, reports, and evidence.
- `templates/`: Canonical templates for `PROJECT.md`, `AGENTS.md`, `PROGRESS.md`, etc.
- `prompts/`: Master entry prompts and phase guidance prompts.
- `registries/`: Canonical capability registries and module maps.
- `memory/`: Vault templates and persistent memory schemas.
- `skills/`: Bundled engineering skills including `taste-skill`.
- `reference-projects/`: Reference implementations (e.g. `DEVTRACK`).
